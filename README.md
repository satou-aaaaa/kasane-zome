# 重ね染め

藍・紅花・刈安・紫根の染め液に布をくぐらせて、見本の**日本の伝統色**を染める1日5色のゲームです。

- 遊ぶ：https://satou-aaaaa.github.io/kasane-zome/
- 「今日の5色」はだれでも同じ色で1日1回。結果は色の絵文字と星の文でシェアできます。
- 上級「記憶染め」は、見本を覚えたら隠して染めます。練習は何度でも。とことんは何色続けて染められるかの挑戦（85%に届かない色があっても、見立てを使っても終わらず、「ここで降りる」まで好きなだけ続けられます）。上級・練習・とことんははじめての日から遊べます。染めた色は色帳に集まります。
- 迷ったら「見立て」（1色に1回）で、見本とのちがいを一言で教えてもらえます。実績と、染めた日のカレンダーもあります。取りこぼした日は7日前まで、あとから染められます。
- 藍に刈安（黄）を重ねると緑になるなど、昔の重ね染めのしくみで色がまざります。時間制限はありません。
- 記録はあなたのブラウザの中だけに残ります。ホーム画面に置くと、電波が無くても遊べます。
